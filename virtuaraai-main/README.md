# Virtuara AI — web app

This folder is the Next.js 14 interface for Virtuara AI.

Setup, architecture, and local run instructions are in the [root README](../README.md).

```bash
npm install
# virtuaraai-main/.env.local
# NEXT_PUBLIC_API_URL=http://localhost:8001
npm run dev
```

The development server listens on **http://localhost:3001**.
